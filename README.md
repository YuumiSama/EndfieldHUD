\# 终末地连携监测



一个基于屏幕识别的《明日方舟：终末地》连携状态监测工具。



\## 功能



\- 实时监测 4 个角色的连携状态

\- 悬浮窗显示在游戏上方，支持多种样式（长条/圆环/饼图/实心圆）

\- 高度可自定义（透明度、圆角、边框、字体、颜色等）

\- 支持预设切换（保存/加载多套样式）

\- 系统托盘、最小化到托盘

\- 不修改游戏文件、不读取游戏内存

\## 安装



1\. 下载 Release 里的压缩包

2\. 解压后双击 `EndfieldHUD.exe`

3\. 在游戏里进入战斗，悬浮窗会自动显示



\## 使用



\- \*\*启动悬浮窗\*\*：主页点"启动悬浮窗"

\- \*\*调整位置\*\*：按住 Ctrl，用鼠标拖动悬浮窗

\- \*\*切换预设\*\*：主页"当前预设"下拉框

\- \*\*修改样式\*\*：设置页调整各种参数
