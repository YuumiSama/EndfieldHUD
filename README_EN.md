\# Endfield Link Monitor



> A screen-recognition based tool for monitoring character link status in \*Arknights: Endfield\*.



🌟 Click the \*\*Star\*\* button in the top right corner to receive update notifications!



\[简体中文](README.md) | \[English](README\_EN.md) | \[繁體中文](README\_TW.md)



\## Features



\- \*\*Overlay\*\*: Real-time monitoring of 4 characters' link status, displayed on top of the game

\- \*\*Multiple Styles\*\*: Supports bar, ring, pie, and solid circle

\- \*\*Highly Customizable\*\*: Opacity, corner radius, border, font, color, and more

\- \*\*Per-character Colors\*\*: Each character's progress bar can have its own color

\- \*\*Charge Highlight\*\*: Glowing effect when a character's charge is full

\- \*\*Preset System\*\*: Save/load multiple style presets, with import/export support

\- \*\*Smart Detection\*\*: Auto-detects the game window, only shows overlay during combat

\- \*\*System Tray\*\*: Minimize to tray, double-click to restore

\## Download \& Install



Go to \[Releases](https://github.com/YuumiSama/EndfieldHUD/releases), download the zip, extract it, and double-click `EndfieldHUD.exe` to run.



\*\*No Python or other dependencies required.\*\*



\## Quick Start



1\. Launch the application

2\. Click \*\*"Start Overlay"\*\* on the home page

3\. Switch to the game and enter combat

4\. The overlay will appear automatically on the screen



\*\*To adjust position\*\*: Hold `Ctrl` and drag the overlay with your mouse



\## Run from Source



Requires \*\*Python 3.12\*\* or higher.



```bash

\# Clone the repository

git clone https://github.com/YuumiSama/EndfieldHUD

cd EndfieldHUD



\# Install dependencies

pip install -r requirements.txt



\# Run

python main.py

```
